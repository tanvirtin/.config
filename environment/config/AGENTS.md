# Agent rules

## Commits and pull requests

- Never add an AI agent as an author or co-author. No `Co-Authored-By:` trailers
  for Claude or any other assistant, and no "Generated with" footers, in commit
  messages or pull request descriptions. Commits are authored by the user alone.
- Before every push, check every commit being pushed, not only the new ones,
  for such trailers or footers, and remove them first.
